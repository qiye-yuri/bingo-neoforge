# 独立实现开发政策

[English](CLEAN_ROOM.md)

本文是一项工程政策，不构成法律意见。

## 允许使用的输入

- 已发布二进制文件在正常游戏过程中可公开观察到的行为。
- 面向用户公开的文档、命令名称、文件格式，以及为实现互操作性所必需的网络行为。
- Minecraft 和 NeoForge 的文档及 API。
- `FUNCTIONAL_SPEC.zh-CN.md` 中不包含实现细节的事实性要求。

## 禁止使用的输入

- 复制、翻译、反编译或改编上游源代码。
- 复制上游美术、贴图、声音、翻译、文案、配置默认值、等级列表、大厅结构、Logo 或截图。
- 复用上游包名、内部类名或具有识别性的品牌元素。
- 在实现对应子系统期间查阅上游的实现代码。

## 贡献记录

每个实现游戏功能的拉取请求都必须说明：

1. 它实现了功能规格中的哪一项要求。
2. 使用了哪一种公开行为或独立设计来源。
3. 未查阅或复制任何被本政策禁止的上游材料。
4. 是否增加了第三方资源或依赖，以及它们的许可证。

如果贡献者已经研究过上游某个子系统的实现代码，则不应负责实现同一子系统。该贡献者可以为另一位实现者编写只描述行为的测试计划，但不得包含实现细节。

## 项目标识和兼容性

使用 `neo_bingo` 作为模组 ID，使用 `dev.cleanroom.neobingo` 作为根包名。在互操作性经过独立验证之前，不得声称本项目是官方移植版、官方续作或可直接替换上游的实现。
