# 功能规格

[English](FUNCTIONAL_SPEC.md)

本文只记录行为要求，刻意不包含任何上游实现细节。

## 核心游戏

- 管理员可以从可配置目标中创建或重新生成一张方形宾果卡。
- 玩家可以在游戏开始前的大厅中加入队伍。
- 目标完成情况由服务器判定；对于给定的种子和配置，其结果应当具有确定性。
- 标准模式下，符合条件的队员完成目标后，其队伍获得对应格子。
- 锁定模式下，某个格子被一个队伍占领后，其他队伍不能再占领该格子。
- 物品栏模式根据符合条件的物品栏状态持续计算格子归属。
- 隐藏模式在满足发现条件之前隐藏目标内容。
- 排位模式持续到时间限制结束，并按照得分排列队伍名次。
- 非排位游戏在达到可配置的连线或得分胜利条件后结束。

## 展示

- 服务器始终是游戏状态的权威来源。
- 原版客户端通过兼容原版的机制获得可使用的宾果卡。
- 安装模组的客户端可以显示独立 HUD 和界面。
- 所有新增美术和文本必须独立创作，或依据有记录且兼容的许可证取得。

## 运维功能

- 命令应覆盖游戏生命周期、种子查看、重新生成、队伍成员管理和紧急结束游戏。
- 配置和宾果卡定义采用数据驱动方式，并带有模式版本号。
- 服务器状态在重启后仍可恢复，并能安全处理玩家断线和重新连接。
