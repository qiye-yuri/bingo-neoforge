# 路线图

[English](ROADMAP.md)

- 建立 NeoForge 项目、CI、许可证、独立实现政策和架构记录。
- 添加客户端和专用服务器的最小加载测试。

- [x] 实现可通过服务端命令选择的标准及锁定模式。

## 阶段 3——客户端体验

- 使用原创资源实现可选的 NeoForge HUD 和宾果卡界面。
- 使用明确的协议协商机制，使原版客户端继续受到支持。

## 阶段 4——集成和加固

- 通过编译期 API 添加可选的配方查看器和语音聊天集成。
- 完善权限、性能测试、兼容性矩阵和发布自动化。

## 架构边界

- `domain`：与模组加载器无关的规则和不可变状态。
- `domain.rule`：由游戏模式选择的独立认领策略。
- `application`：命令和应用用例。
- `neoforge`：事件、持久化适配器、网络和生命周期。
- `client`：只包含可选界面和渲染。

领域层测试不得启动 Minecraft。NeoForge GameTest 用于验证适配器行为。
